#1 แก้ input_text escape อักขระพิเศษให้ครบ
mumu_controller.py:203 · รหัสผ่านที่มี & ( ) < > ' " $ กรอกไม่ผ่าน
▶
ทำไม: ตอนนี้ escape แค่ช่องว่าง (%s) เท่านั้น คอมเมนต์ในโค้ดก็ยอมรับเอง ถ้า password มีอักขระพิเศษ ADB shell จะตีความผิด → ไอดีนั้น login/สมัครไม่ผ่าน โดยไม่มี error น่าจะเป็นต้นเหตุที่บางไอดีพลาดแบบหาสาเหตุไม่เจอ

ขั้นตอน

  1. ใน input_text() เปลี่ยนวิธีส่งข้อความ — escape อักขระพิเศษของ shell ทุกตัว ไม่ใช่แค่ช่องว่าง
  2. ทางที่ปลอดภัยสุด: ส่งทีละอักขระ หรือใช้ am broadcast ผ่าน ADBKeyboard IME แทน input text สำหรับอักขระพิเศษ
  3. ทางเร็ว: ครอบข้อความด้วย quote + escape \\ " ' $ ` & | ; ( ) < > ! space
  4. เพิ่มเทสใน tests/: ป้อน password ที่มี P@ss&w(rd)! แล้ว assert คำสั่งที่ออกไปถูก escape
